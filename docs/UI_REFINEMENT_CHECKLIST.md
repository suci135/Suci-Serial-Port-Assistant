## 视觉规则

- 保持项目现有字体及字号基线，不替换字体。
- 主要操作使用强调色；删除和错误才使用红色。
- 模块优先依靠背景层级、留白和圆角分区，避免贯穿界面的硬分割线。
- 深色模式不使用纯黑大底或纯白次要按钮；文本分为主要、次要、弱提示三级。
- 所有新增功能先进入独立核心模块，再由 UI 通过公开接口调用。
