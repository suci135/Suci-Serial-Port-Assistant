## 目标模块结构

```text
src/
├── transports/       # Serial、BLE、TCP、UDP、HID 的统一接口
├── protocols/        # 组帧、转义、校验、协议解析器
├── automation/       # 序列、Expect、测试用例、报告
├── sessions/         # 记录、索引、回放与导出
├── visualization/    # 数据集、变换和图表模型
├── services/         # 工作区、通知、诊断、插件管理
└── ui/
    ├── design/       # 颜色、间距、圆角、动效令牌
    └── workbench/    # 侧栏、终端、发送器、检查器
```
