# Apple 风格工作台重构规范

## 设计目标

- 保持当前应用字体加载逻辑与字号基线不变。
- 让最高频的“观察数据”和“发送命令”占据最大空间。
- 高级参数按上下文出现，不把所有功能永久摊在侧栏。
- 窗口缩放时连续重排，不跳档、不遮挡、不让输入区消失。
- Apple 风格来自层级、材质、反馈、熟悉性和克制，不是简单堆叠圆角与毛玻璃。

## 新版布局

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 窗口控制 │ 当前工作区 / 会话       连接状态     搜索  录制  更多       │
├──────────┬───────────────────────────────────────────────┬───────────────┤
│ 导航侧栏 │ 终端 / 图表 / 数据表 / 会话                  │ 上下文检查器  │
│          │                                               │ 参数/命令/自动化│
│ 连接     │                主数据视图                     │               │
│ 会话     │                                               │               │
│ 配置     ├───────────────────────────────────────────────┤               │
│          │ 格式  输入内容                     CR LF 发送 │               │
├──────────┴───────────────────────────────────────────────┴───────────────┤
│ 连接信息  RX/TX 速率  帧数  错误  录制时长                              │
└──────────────────────────────────────────────────────────────────────────┘
```

## 关键位置变化

- 发送输入从右栏移动到中央内容底部，和接收终端形成直接上下关系。
- 串口详细参数从常驻左栏移动到右侧“参数”检查器。
- 快捷命令与自动化序列共享右侧检查器，避免同时占用垂直空间。
- 左栏只保留导航、连接对象和会话列表；连接/断开是唯一高强调动作。
- 搜索、录制、暂停、清屏进入主工具栏；导出与低频操作进入“更多”。

## 响应式规则

| 宽度 | 布局行为 |
| --- | --- |
| `>= 1240 px` | 三栏完整显示；左右栏可拖拽，右栏可折叠 |
| `960–1239 px` | 左栏收窄，右栏默认折叠为检查器按钮 |
| `720–959 px` | 左栏变为图标导航；右栏使用覆盖式面板 |
| `< 720 px` | 单主视图；导航和检查器均为临时抽屉；发送器保持可见 |

响应式变化使用窗口尺寸和用户拖拽即时计算；不使用耗时的逐帧几何动画。侧栏显隐采用可中断、短时的 `ease-out`，高频键盘操作不播放动画。

## 视觉令牌

| 类型 | 建议值 |
| --- | --- |
| 主背景 | `#F5F5F7` / 深色 `#1C1C1E` |
| 内容表面 | `#FFFFFF` / 深色 `#242426` |
| 侧栏材质 | 半透明中性色，必要时回退为不透明表面 |
| 主强调色 | `#0A84FF` |
| 成功/警告/错误 | `#30D158` / `#FF9F0A` / `#FF453A` |
| 间距 | `4, 8, 12, 16, 20, 24` |
| 圆角 | `6, 8, 10, 12`；整窗 `14` |
| 控件高度 | 紧凑 `28`，标准 `32`，主操作 `36` |

## 交互与可访问性

- 按下时立即反馈；连接、断开、发送、停止等状态在同一控件中连续变化。
- 焦点环必须清晰；所有图标按钮有工具提示和键盘操作。
- 不依赖颜色单独传达连接、错误或校验状态。
- 支持减少动态效果和高对比度；毛玻璃不可用时保证实体背景可读。
- 终端大量数据刷新与窗口缩放解耦，避免布局重算阻塞 I/O。
