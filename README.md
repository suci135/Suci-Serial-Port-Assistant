# Suci的串口助手

一个基于 PyQt6 的现代化串口调试工具，采用 macOS 原生风格设计。

## ✨ 特性

- 🎨 **macOS 风格界面** - 简洁优雅的用户界面设计
- 🔌 **串口通信** - 支持多种波特率、数据位、停止位、校验位配置
- 📊 **多种数据格式** - 支持 HEX、ASCII、UTF-8 格式显示和发送
- 📈 **实时统计** - 实时显示发送和接收的数据统计
- ⚡ **高性能** - 基于异步事件循环，响应迅速

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows / macOS / Linux

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行程序

```bash
python main.py
```

## 📦 依赖项

- PyQt6 - GUI 框架
- pyserial - 串口通信
- qasync - 异步事件循环

## 🎯 使用说明

1. **选择串口** - 在左侧边栏选择要连接的串口
2. **配置参数** - 设置波特率、数据位、停止位、校验位
3. **连接串口** - 点击"连接"按钮建立连接
4. **发送数据** - 在右侧输入框输入数据，选择格式后点击"发送"
5. **查看数据** - 中间黑色区域实时显示接收到的数据

## 🎨 界面特点

- **无边框窗口** - 自定义标题栏，支持拖动和全屏切换

- **红黄绿按钮** - macOS 风格的窗口控制按钮
- **深色显示区** - 黑色背景白色文字，便于长时间查看数据
